## Tech Stack
- Backend: Node, Express.js
- Frontend: HTML, CSS, JS, CodeMirror editor 

## Installation
1. Frontend setup
   - Open a terminal in the project root
   - `cd frontend`
   - `npm install`


## Implementation
- Node.js + Express frontend server
- Code editor UI built with CodeMirror
